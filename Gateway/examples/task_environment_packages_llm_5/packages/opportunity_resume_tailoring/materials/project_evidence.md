# 项目证据记录

## 客户健康度评分模型搭建与预警运营项目
- 角色：项目核心负责人
- 动作：
  - 梳理客户关键行为指标，选取登录频次、功能使用深度、工单提交量等维度作为评分因子
  - 使用SQL从数据仓库提取客户行为数据，通过Python进行权重回归分析确定各因子权重
  - 设计健康度分级预警规则，与客户成功团队协同建立分级响应SOP
- 结果：
  - 模型覆盖活跃客户1200余家，高风险客户识别准确率达到82%
  - 预警机制上线后季度客户流失率环比下降3.2个百分点
- 技能：SQL、Python、客户成功运营、数据看板搭建

## 新客户Onboarding流程数字化改造项目
- 角色：项目执行负责人
- 动作：
  - 访谈8家典型客户梳理上线全流程节点，识别关键卡点与人工跟进瓶颈
  - 设计自动化触发规则与里程碑提醒机制，配置系统内引导任务与邮件通知
  - 搭建Onboarding进度数据看板，实时监控各阶段转化率与平均耗时
- 结果：
  - 客户首次价值实现时间从14天缩短至9天
  - Onboarding阶段人工跟进工时减少约30%
- 技能：用户旅程分析、需求文档撰写、A/B测试、数据看板搭建
